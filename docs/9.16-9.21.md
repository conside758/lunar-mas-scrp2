## 一、场景复杂化：6 机器人任务选择（设计 + 实现）

### 1.1 设计决策（按用户给定 + 文献）

- **机器人**：3 → 6 台，scout / excavator / hauler **各 2 台**（用户指定）。
- **depot**：2 个——主卸载点 (-2.0, -1.5)、次级卸载点 (2.5, 2.0)（后者靠近水冰/钛铁矿簇，制造「运到哪个 depot」的选择）。
- **资源价值**（参考月球 ISRU 相对价值：水冰 > 钛铁矿 > 月壤）：
  - 水冰 value **3**（量 12 + 10，少而贵）
  - 钛铁矿 value **2**（量 20 + 18）
  - 月壤 value **1**（量 25 + 22 + 20 + 24，多而贱）
  - 8 资源总量 151、总价值 **233**；限时 **120s**（240 步）——时间受限，逼出「选哪个资源 / 哪个 depot」的权衡。
- 规则基线：**贪婪拍卖** bid = value/(1+distance)（简单、确定性、但非全局最优，学习策略可超越）。

## 三、两个关键问题的澄清（用户提出）

### 3.1 资源参数变化是否造成「注意力 >> 展平」结论的逻辑漏洞？

**是，存在一个需要正视的口径漏洞。**

| 参数 | 旧（3 机器人） | 新（6 机器人） |
| --- | --- | --- |
| 机器人数 | 3 | 6 |
| 资源数 | 3 | 8 |
| 资源总量 | 60 | 151（2.5×） |
| 资源价值 | 全 1.0 | 1 / 2 / 3 异构 |
| depot | 1 | 2 |
| 限时 | 120s | 120s（不变） |

- 「143 vs 24」这个 6 倍差距**同时混杂了两个变量**：① 实体规模变大（资源 3→8、机器人 3→6，展平定长观测难学得多）；② 真的引入了任务选择（异构价值 + 双 depot）。
- 因此**不能把 143 vs 24 干净地归因于「任务选择」**；它严格证明的是「实体更多/场景更难的条件下，注意力远优于展平」。
- 干净的「注意力 vs 展平」结论来自**更早的对照**（3 机器人、只变资源数 3~6，无任务选择混杂）：低数据时注意力 29.5 vs 展平 12.3。
- **处理**：补对照实验（同实体规模下「均匀价值+单 depot」vs「异构价值+双 depot」）**暂时搁置**（按用户意见）。

### 3.2 换成 AWAC / TD3+BC 后，HAPPO 还有主体性吗？

**有，但取决于「保留什么」。**

- HAPPO 的主体性 = **反事实多智能体优势 A_i=Q(s,a)−Q(s,a_cf_i)（异构信用分配）** + 逐智能体顺序更新 + 信任域。
- AWAC / TD3+BC 只替换**「策略更新规则」**（PPO ratio-clip → 优势加权回归 / BC 正则），本身**不提供多智能体信用分配**。
- 结论：**保留反事实优势 A_i 作 AWAC 的 exp(A_i/λ) 权重（或 TD3+BC 里的 Q），HAPPO 主体性保留**；若连反事实一起丢掉，才真正失去主体性。
- 落地口径：**「AWAC 式更新 + HAPPO 反事实优势」**（§四照此实现）。

## 四、RL 精修改法尝试：AWAC（优势加权回归）—— 未改善

- 实现 `train_awac.py`：BC 策略随机 rollout 收集多样示范 → 拟合集中 QCritic Q(s,a) →
  逐 Agent 反事实优势 A_i=Q(s,a)−Q(s,a_cf_i) 做 **exp(A_i/λ) 加权回归**（保留 HAPPO 反事实优势作信用分配）。

| 方案 | value（/233） |
| --- | --- |
| 规则基线 | 191.0 |
| 角色感知 BC | 143.0 |
| 角色感知 HAPPO 反事实（PPO 精修） | 118.0 |
| 角色感知 AWAC（λ=1.0） | 106.0 |
| 角色感知 AWAC（λ=3.0） | 0.0（坍缩） |

- **结论**：AWAC 也未改善（106 < BC 143，λ=3.0 坍缩到 0）。与 PPO 同一根因：交付价值不连续 → 优势噪声大 → 优势加权放大噪声、推离 BC 均值。

## 五、奖励改进：压 Q 噪声 —— 有效降噪、但仍无法改进 BC

- 奖励改动（`surrogate.py`）：① **去掉离散「探测」一次性奖励**（发现状态照常更新，探索改由 app 势函数驱动）；② **价值归一化**（奖励按 value/value_norm 缩放，value_norm=最大价值 3，`delivered_value` 指标保持真实价值不变）。

| 指标 | 旧奖励 | 新奖励 |
| --- | --- | --- |
| value_loss（Q 噪声） | 5~17 | **1~5（降 3~5×）** |
| HAPPO 反事实（无 CQL） | 坍缩 0 | 仍坍缩（噪声非唯一根因） |
| HAPPO 反事实（+CQL+reset-std+强 KL+低 lr） | 118 | 振荡后**回到 143（=BC）**，不再永久坍缩 |

- **结论**：改进奖励**确实压低了 Q 噪声 3~5×**（目标达成）；配合 CQL + 近确定性 std + 强 KL + 低 lr 后，HAPPO 反事实从「永久坍缩」变为「振荡后回到 BC 143」——但**仍无法改进 BC 逼近规则（191）**。
- **定位**：噪声/坍缩已解决，但「无法超过 BC」是**另一个问题**——HAPPO 反事实优势在近确定性策略下 A_i≈0 → 天然「冻结」在 BC。下一步若要改进，需打破冻结（MaxEnt/熵、或价值函数更准、或换优势估计）。

**当前最优**：角色感知 BC = **143（规则 75%）**；规则基线 = 191（最优整体）。「RL/优势基精修能否稳定改进 BC」在 6 机器人任务选择场景**仍未突破**。

**待办（候选）**：
1. （搁置）补「任务选择」对照实验（隔离「更多实体」vs「任务选择」）。
