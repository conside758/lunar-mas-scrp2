## 任务 C：角色感知 HAPPO/HASAC（核心创新，优先级高）

**前置**：3 个独立 Actor + 1 Critic 已就绪（参数级异构），此为升级到「结构/角色感知级异构」。

**HAPPO（先做，改动小）—— 方法验证 ✅、严格「≥」未达标 ⚠️（2026-09-14，5 种子）**：
1. **角色专属观测**：scout 去 cargo 等，各车 obs 维度按角色定制（先保留统一 32 维也行，逐步拆）。
2. **角色嵌入 + 队友/资源注意力**：已实现 `RoleAwareActor`（对 3 资源 + 2 队友实体 dot-product
   注意力池化），`train.py --role-aware` 开关。替身 Stage 2 BC 交付 36.0。
3. **异构训练动力学**：已实现 HAPPO 顺序更新（逐 Agent 独立优化器 + 各自 trust region）**并补齐
   HAPPO 核心——反事实优势 A_i = Q(s,a) − Q(s,a_cf_i)**（`QCritic` + `encode_joint_action`，
   `--hap` 开关，`--critic-lr` 给 Q 独立学习率）。
   **消融（5 种子 seed 1~5，Welch 双侧）**：无角色 MAPPO=40.80±4.38 / 角色感知 MAPPO=28.60±5.08 /
   角色感知 HAPPO(反事实)=**36.00±0.00**（5 种子全 36）。
   - ✅ 反事实基线显著修复角色感知：D(36.0) > C(28.6)，**p=0.0011**；旧版无反事实仅 20.0。
   - ⚠️ 严格「角色感知 HAPPO ≥ 无角色 MAPPO」**未达标**：D(36.0) < A(40.8)，**p=0.014**——固定
     3 车/3 资源场景里普通 Actor+MAPPO 能把 BC 改进到 44（5 种子中 3 次），注意力压不出优势。
   详见 `docs/模型训练方案.md` §9.1。下一步：变规模/动态重规划场景或角色专属观测/角色级 shaping。

**HASAC（后做，改动大）—— 已实现、本场景不如 HAPPO ⚠️（2026-09-14）**：
- ✅ 已实现 `hasac.py` + `train_hasac.py`：3 个逐 Agent 软 Q Critic（Q_i(s,a_i)）+ 熵正则软 Bellman
  （SAC，温度 `--alpha`）+ 逐角色奖励 shaping（`surrogate.per_agent_reward`）。
- 5 种子消融：普通 Actor+HASAC=32.0±6.9、角色感知 HASAC=28.8±5.0，**均低于反事实 HAPPO
  （B=34.4 / D=36.0±0.0）**。机制：SAC 熵最大化目标持续漂移近确定性策略，反事实优势在 a≈a_cf 时
  自然冻结 BC。故本项目**首选反事实 HAPPO**；HASAC 保留为「从零训练/强探索」场景的备选。
- 详见 `docs/模型训练方案.md` §5.4/§9.1。

**每步验收**：角色感知版交付量 ≥ 无角色 MAPPO 基线（统计显著、多种子）。
