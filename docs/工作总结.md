## 2. 关键技术问题与根因

### 2.1 车轮方向/轴向错误（本次最关键的根因发现）

**现象**：挖掘/运输车正 `linear.x` 时倒退，且伴随严重打滑（车轮 ~5 rad/s 但车体仅 ~0.01 m/s）与侧向漂移（dx≈dy）。

**根因**：车轮 URDF 中 `rpy="1.5708 0 0"` 会把关节坐标系绕 X 轴旋转 90°，导致关节轴
`0 1 0` / `0 -1 0`（关节系）实际映射到父系的**竖直 Z 轴**。结果车轮一直绕竖轴自转
（像陀螺），而非绕水平轴滚动——所以「车轮在转、车体几乎不动、且侧向漂移」。

**修复**：将关节轴改为 `0 0 1`（再定方向为 `0 0 -1`），使旋转轴落在圆柱长度方向
（父系水平轴）。修复后车轮真正滚动，挖掘/运输车 **4 秒直线前进 1.2~1.4 m**（无侧漂）。

> 过程中还验证过 `velocity_pid`（扭矩 PID）与「4 轮滑移转向」两种方案：前者增益易失稳、
> 后者转弯极慢（滑移转向需侧向滑移，被摩擦抵抗），最终回退到「2 驱动轮 + 2 低摩擦滑垫」
> 的经典差速方案（转弯由 2 轮差速 + 滑垫滑动完成，快速稳定）。

## 5. 遗留问题（后续可优化）

1. **Scout 步态较慢**（~0.035 m/s）：当前为对角小跑关节空间近似，能前进但不快，可调参或改三足爬行/IK 提速。
2. **轮式车前进效率约 60%**（命令 0.5 m/s，实际 ~0.3 m/s）：仿真摩擦/滑垫所致，不影响闭环，但若需更真实动力学可继续调优。
