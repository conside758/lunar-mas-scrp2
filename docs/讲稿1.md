# 讲稿 1 —— 阶段汇报提纲

> 用途：向他人（导师/团队）汇报 9.1–9.8 阶段进展。
> 用一句话开场：**「我们的多机器人采矿学习策略，已经在 Gazebo 里自己跑通了『挖—装—运—卸』完整闭环。」**

---

## 一、背景与目标（1 分钟）

- 项目：月球多机器人协同采矿（Scout 探测 / Excavator 挖掘 / Hauler 运输），参考 NASA Space Robotics Challenge Phase 2 简化规则。
- 方法主线：**角色感知的异构多智能体强化学习（MARL）**，先跑通无角色的 MAPPO 基线，再做角色感知 HAPPO/HASAC。
- 本阶段目标：让「学习到的策略」在 Gazebo 里达到规则基线的水平（这是后续角色感知对比的**下界**）。

## 二、本阶段做了什么（2 分钟）

1. **架构重构**：把「三车共用一个 Actor」改成「**3 个独立 Actor + 1 个集中 Critic**」
   （消除角色间干扰，为角色感知打底）。
2. **观测/奖励打磨**：观测加「车体系子目标」、去掉会漂移的速度量；奖励修了势函数的目标切换 bug。
3. **啃下最难的迁移问题**（本阶段核心）：
   - 替身环境里训练的策略，一上 Gazebo 就失效（0~4 分）。
   - 逐层定位根因：真实机器人「原地转向」其实不慢（~50% 效率），慢的是「边前进边转向」（~8%）；
     而 BC 恰好会把「原地转向」学成「慢速前进+转向」。
   - 解法：**直接在 Gazebo 里收集规则示范做 BC + DAgger**，用真实动力学训练。

## 三、结果（1 分钟，重点看数字）

| 环境 | 规则基线 | 学习策略 |
| --- | --- | --- |
| 替身（理想） | 44 | 36~44 ✅ |
| **Gazebo（真实）** | **10~22（记录 16）** | **14.0 ✅（收敛）** |

- 一句话：**学习策略在真实仿真里交付 14.0，达到规则基线量级**，能自主完成挖→装→运→卸。
- 过程曲线：替身迁移 0 → Gazebo 内 BC 0（差临门一脚）→ +DAgger 8 → 14 → 14。

## 四、几个值得说的技术点（1 分钟）

1. **「车体系子目标」**：给网络喂目标在车体坐标系下的坐标，让「去目标」这个低层技能可被回归学习（否则转向符号都学反）。
2. **BC 的固有平滑**：模仿学习会把规则的硬阈值（原地转向）磨平，正好踩中真实机器人的最差工况。
3. **sim-to-sim 迁移的坑**：不能只靠速度缩放做域随机——「组合运动退化」（边转边走）比单纯变慢严重一个量级。

## 五、结论与展望（1 分钟）

- **已达**：3-agent-1-critic 基线跑通，Gazebo 交付 14.0（规则基线量级）。
- **还差**：14 → 16 的最后一小步（再多一轮 DAgger / RL 精修）。
- **下一步**：
  1. 把 Gazebo 交付推到 ≥16；
  2. 转入**角色感知 HAPPO/HASAC**（核心创新点，架构已就绪）；
  3. 做一个「学习策略采矿」的可视化 demo。

## 附：可能被问到的问题（预备答）

- **Q：为什么不是端到端 RL 直接训，而要 BC/DAgger？**
  A：协作链「挖→会合→装→运→卸」是多阶段稀疏回报，端到端 RL 从零很难串起来；用规则示范
  预热（BC）再迭代纠偏（DAgger），是稳定又快的做法。
- **Q：14.0 比规则 16 低，算达标吗？**
  A：规则基线本身在 Gazebo 有噪声（10~22），14 已在其区间内、逼近记录值；差的是最后一小步，
  属可继续逼近的工程问题。
- **Q：Scout 在这阶段干什么？**
  A：Stage 1 资源位置已知，Scout 尚无功能角色（只巡视）；真正让 Scout 起作用的是 Stage 2（加腿式传感器、未知地形），后续接入。
