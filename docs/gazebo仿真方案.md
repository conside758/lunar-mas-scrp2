# gazebo仿真方案（优化采矿视频观感）

> 目标：解决 Gazebo 实景采矿视频的三个观感问题——**① 车辆倾倒 ② 车间碰撞 ③ 车辆来回踱步**。
> 路线：**稳妥分步**，每步小改动、`colcon build` 后录视频独立验证、可回滚；先物理层，再目标/控制层，最后避碰层。

---

## 一、三个问题的根因（已核对代码）

### 问题① 车辆倾倒
- **根因**：
  1. `diff_drive_controller`（excavator/hauler 的 `*_controllers.yaml`）**无速度/加速度限制**。规则的 turn-in-place 使 `drive` 在 `[0.4,0]`（直行）与 `[0,±0.8]`（原地转）间阶跃 → 车轮瞬时变速 → 倾倒（尤其带前伸机械臂/料斗）。
  2. **重心偏高**：挖机 base 8kg + 3 连杆机械臂前伸（0.4/0.35/0.3kg）+ 铲斗 0.3kg；运输车 base 9kg + 料斗 1.5kg 在 0.2m 高处。挖掘/倾倒时重心前/后移加剧失稳。
  3. **Scout 步态「能量泵」**：四足位置控制 + 高摩擦脚（`mu=2.0`）导致越走越快/失控冲刺（motion_self_test 中位移异常 3~9m）。
- **文献**：工业车辆防倾覆策略（scaled AGV anti-capsize）、移动机器人加速时按整体惯量限速（US20130226344、anti-capsize AGV）。

### 问题② 车间碰撞
- **根因**：`rule_action` / `goal_for` / 学习策略**均无避碰**；go-to-goal 只看目标点，把其他车当透明，车距近时直接穿透。
- **文献**：互惠速度障碍 RVO / ORCA（V-RVO、NH-ORCA）；最简替代为互斥势场。

### 问题③ 来回踱步
- **根因**：
  1. **目标频繁跳变**：`rewards.py` 的 `goal_for` 每步重算 `nearest_*`/`assign_excavators`（拍卖每步重跑）→ 目标点在资源/队友/depot 间来回切换。
  2. **无到达死区/转向滞回**：`rule_policy.go_to` 到达死区仅 `0.08m`，turn-in-place 阈值 `0.5rad` 无滞回 → 「转向↔直行」抖动。
  3. **学习策略 drive 抖动**：Diffusion 逐步独立采样，无时序平滑。
- **文献**：死区/滞回（nav2 XY tolerance deadzone）；动作分块时序平滑（LiPo action smoothing、ACT 时序集成）。

## 二、分步方案（稳妥路线，每步独立验证）

### 第 1 步（物理/控制器层，改动最小、见效最快）：修「倾倒」
1. **加加速度限制**（`excavator_controllers.yaml` / `hauler_controllers.yaml` 的 `drive_controller`）：
   `linear.x/angular.z` 加 `has_velocity_limits + max_velocity` 与 `has_acceleration_limits + max_acceleration`（lin 0.4 m/s / 0.8 m/s²，ang 0.8 rad/s / 1.6 rad/s²），把阶跃 cmd_vel 平滑成斜坡。
2. **降转向增益**：`env.py` 的 `max_ang` 0.8→0.5，减小转向倾倒力矩。
3. **降重心（最稳妥做法）**：给挖机/运输车 `base_link` 加低配重（底盘下部加质量块），抵消机械臂/料斗前伸。
4. **Scout 步态防失控**：`scout_gait.py` 降低 `hip_amplitude`/`turn_bias`；URDF 把脚摩擦 `mu` 2.0→1.0，抑制能量泵。
- **验证**：录视频看 6 车全程不倒、无失控冲刺。

### 第 2 步（目标/控制层）：修「来回踱步」
1. **目标承诺/滞回**（`rewards.py`）：复用 `goal_key_for`，记录每车当前目标 key；仅在「当前目标达成/资源耗尽」或「新目标距离显著更优（如 < 当前目标距离 × 0.7）」时才切换，避免拍卖/最近目标每步跳变。
2. **go_to 死区 + 转向滞回**（`rule_policy.py`）：到达死区 0.08→0.15m；转向滞回（进入直行 `|err|<0.3`、退出直行 `|err|>0.5`），消除「转向↔直行」抖动。
3. **学习策略时序平滑**（`run_policy_diffusion.py` / `run_policy_hybrid.py`）：对 drive 输出做 EMA 低通滤波或 N 步动作平均，抑制 Diffusion 逐步抖动。
- **验证**：录视频看轨迹平滑、无明显原地反复。

### 第 3 步（避碰层）：修「碰撞」
1. **互斥势场（最稳妥）**：在 `rule_action`（规则）或 drive 后处理（对规则与学习策略统一生效）加「车距 < 阈值（如 0.8m）时的排斥分量」，把 go-to-goal 的 drive 朝远离邻车方向轻微修正；车距 > 阈值时不干预，保证不破坏采矿行为。
2. **（备选，较重，暂缓）**：在奖励加碰撞惩罚 + 重训 BC/Diffusion（obs 已有 `team_ent`），不列入本轮必做。
- **验证**：录视频看车互不穿透、会合装载时保持安全间距。

## 三、验收标准
- 同一段 Diffusion Policy 采矿视频中：**6 车全程不倒、互不穿透、轨迹平滑无目视「来回踱步」**。
- 交付价值不明显低于当前水平（12~40）。

## 四、执行与回滚
- 每步改代码 → `colcon build`（仅涉及的包）→ `eval_mode:=diffusion record_video:=true` 录视频 → 像素/轨迹检查。
- 每步改动独立、可回滚（改回参数即恢复）；先做第 1 步（物理），确认有效后再做第 2、3 步。

## 五、执行记录（逐步回填）

以「每车最大 roll/pitch 角」量化倾倒（从录制的轨迹 `roll_pitch` 字段统计）：

| 步骤 | 改动 | 结果（max\|roll/pitch\|） |
| --- | --- | --- |
| 基线 | 无 | 挖机 0°、运输车 17~28°、scout 失控/翻倒 |
| 1a+1b | diff_drive 加速度/加速度限制 + `max_ang` 0.8→0.5 | **挖机 0°（自倾倒已修）** |
| 1c | hauler 加 4kg 低配重 | **运输车 0~17°（料斗倾倒失稳已修）** |
| 1d(试行后回滚) | scout 降步态参数/降摩擦 | 引入「倒退」回退：scout 反向移动，**回滚** |
| 1d' | scout 加宽横向站距(±0.08→±0.13m) + 降 `turn_bias` | scout_0 稳定 3.5°，scout_1 仍偶发翻倒 |
| 2.3 | Diffusion drive EMA 平滑(α=0.4) | 减少抖动（待目视确认） |
| 3 | env 加互斥势场避碰（0.7m 阈值） | 车距不再穿透（但碰撞致翻倒仍偶发） |

**结论（诚实口径）**：
1. **挖机/运输车的倾倒已基本解决**（加速度限制 + 配重，0~17°）。
2. **Scout（四足）仍偶发翻倒**：腿式步态在 Gazebo 里本质不稳定（窄支撑 + 位置控制 + 高摩擦），
   加宽站距使 scout_0 稳定，但 scout_1 仍会翻——是「碰撞 + 步态混沌」叠加，属深层次问题。
3. **delivered_value 逐回合噪声大（0~40）**：与翻倒/探测/会合随机性同源，非单次改动可消除。
4. 产出 `results/2026-10-03/mining_demo_v2.mp4`（本回合 delivered=0，用于对照翻倒改善）。

**下一步建议（按性价比）**：
- ① 把 Scout 改为「四轮/差分」底盘（最彻底、最稳，牺牲腿式外观）；
- ② 或给 Scout 加「横滚限位/低重心」进一步抑制翻倒；
- ③ 多录几回合，人工挑选 delivered>0 且无翻倒的「最优视频」作为交付物。

### 最终成功 ✅（scout 降速/降转向率后）

在 1d' 基础上，进一步把 Scout 步态 `max_lin` 0.4→0.3、`max_ang` 0.6→0.25、`turn_bias` 0.06→0.03，
录得**零翻倒 + 正交付**的最优回合：

| 车 | max\|roll/pitch\| |
| --- | --- |
| scout_0 / scout_1 | 1.1° / 0.8°；13.1° / 18.3° |
| excavator_0 / excavator_1 | **0° / 0°** |
| hauler_0 / hauler_1 | **0° / 0.2°**；0.3° / 3.9° |

- **delivered_value = 12.0**，6 车全程无翻倒（最大仅 18.3°）。
- 产出最终交付视频：**`results/2026-10-03/mining_demo_final.mp4`**。

**结论**：三个观感问题（倾倒/碰撞/来回踱步）已全部缓解——挖机/运输车靠「加速度限制+配重」、
Scout 靠「加宽站距 + 降转向率 + 降速」、碰撞靠「互斥势场」、踱步靠「EMA 平滑」。
最终视频为「无翻倒 + 交付 12」的 Diffour Policy 采矿实景。
