# 讲稿 2 —— 阶段汇报提纲（9.9–9.15）

> 用途：向他人汇报本阶段进展。按此提纲展开即可；每节给「要点 + 关键数字 + 一句结论」。

---

## 0. 开场（30 秒）

- 项目：月球多智能体采矿——Scout 探测 / Excavator 挖掘 / Hauler 运输，角色固定互斥。
- 技术路线：CTDE 异构 MARL（MAPPO → HAPPO → HASAC）+ BC/DAgger 预热 + 变规模/动态重规划。
- 本阶段目标：把「角色感知」真正做出优势（验收标准 ②：角色感知 HAPPO/HASAC ≥ 无角色 MAPPO）。

---

## 1. 本阶段干了四件事（1 分钟）

1. **修好了 HAPPO**：补上缺失的核心「反事实优势」A_i = Q(s,a) − Q(s,a_cf)。
2. **实现了 HASAC**：逐 Agent 软 Q + 熵正则 + 逐角色奖励 shaping。
3. **搭了变规模/动态重规划场景**：可变资源实体 + 掩码注意力 + 资源耗尽重生。
4. **调研 + 三招稳定性改进**：RLPD / Cal-QL / 镜像学习信任域。

---

## 2. 关键结果（3 分钟，核心）

### 2.1 固定场景 7 单元消融（一张表）

| | 均值 ± std | 一句话 |
| --- | --- | --- |
| A 无角色 MAPPO | 40.80 ± 4.38 | 基线（能把 BC 36 改进到 44） |
| D 角色感知 HAPPO 反事实 | **36.00 ± 0.00** | 零方差，但只回到 BC、无法向上 |
| C 角色感知 MAPPO | 28.60 | 被 RL 洗掉 |
| F 角色感知 HASAC | 28.80 | 熵最大化持续漂移 |

**讲两个点**：
- 反事实把角色感知从 28.6 救回 36.0（p=0.0011）——方法核心成立。
- 但「角色感知 ≥ 无角色」没达成（36 < 40.8，p=0.014）——固定场景压不出注意力。

### 2.2 变规模/动态重规划（补上缺口）

- BC 层面：20 回合数据下，注意力 **29.5** vs 展平 **12.3**（3 种子全胜）；
  动态重生下注意力 **25.3** vs **12.9**，且注意力能重新探测（重规划事件 1.1 vs 0.2）。
- **结论**：注意力的价值在「变规模泛化 + 动态重规划」，固定场景确实测不出来。

### 2.3 但 RL 精修会洗掉 BC（诚实）

- 变规模接 RL 后：角色感知 HAPPO 从 BC 36.1 跌到 **16.8**，展平 MAPPO 反而稳（31.1）。
- 三招（RLPD / 保守 Q / 信任域）都没能稳健救回来。

---

## 3. 遇到的问题（1 分钟，坦诚）

1. RL 精修（BC 后）不稳定、洗掉 BC —— 全局瓶颈。
2. 注意力对 RL 漂移更敏感；展平+共享优势反而最稳。
3. 交付量指标不连续 → Q 噪声大、方差高。
4. HAPPO「冻结」在 BC，无法向上（次优收敛）。
5. Gazebo Stage 2 学习策略卡在 Scout 探索（规则基线已通 20.0）。

| 方法 | 结果 | 教训 |

## 5. 结论与下一步（30 秒）

- **结论**：角色感知的价值在 BC 层面（变规模 + 动态重规划）已被验证；RL 精修稳定性是结构性瓶颈，暂未突破。
- **两条路（待定）**：
  - A. 以 BC/DAgger 为最终策略，用「变规模 BC 注意力 ≥ 展平」作为角色感知验收证据；
  - B. 换平滑/稠密奖励从根上降 Q 噪声，再做 RL。

---

## 6. 可能被问到的 QA（备答）

- **为什么固定场景注意力没用？** 展平观测已够表达任务，注意力只是加参数/加优化难度。
- **HAPPO 为什么冻结？** 标准目标会收敛到确定性次优纳什（HASAC 论文的矩阵博弈已证明），缺熵/探索。
- **为什么 RL 洗掉 BC？** 交付不连续 → Q 噪声 → 优势漂移；注意力放大漂移。
- **下一步最有希望是什么？** 方向 A（BC 为最终）最稳；方向 B（平滑奖励）更治本但工作量大。
