- 奖励改为**分量累加**（`dig/load/deliver/app/step`），`info` 暴露 `reward_breakdown`，便于定位。

### 2.2 奖励修正 `rewards.py`
- 新增 `goal_key_for()`：返回每车目标的「身份」键，用于检测目标切换。
- **修复势函数塑形在目标切换时的虚假跳跃**（`surrogate.py` 中目标身份变化时重置势能基线）。
- `app` 权重 0.2 → 1.0（强化「去目标」的密集信号）。

### 2.3 观测编码 `obs.py`（**本日最关键突破**）
- 每车观测从 27 维扩展到 **31 维**：新增「相对当前子目标」的**世界系 [dx,dy]** 与
  **车体系 [dx,dy]** 两组特征。
- **根因**：BC 回归无法学习 `go_to` 控制器里的 `atan2(dy,dx) − yaw`（带环绕的角度减法）。
  原始 obs 里只有原始 yaw + 世界系目标，网络算不对转向方向（转向符号都学反）。
- **解法**：把子目标旋转到车体系 `[dx·cos(yaw)+dy·sin(yaw), −dx·sin(yaw)+dy·cos(yaw)]`，
  网络只需学「车体系目标向量 → 转向/前进」，不再做角度减法。改后 BC 从 0 直接到满分。

### 2.4 规则策略平滑 `rule_policy.py`
- `go_to` 前进速度去掉 `max(0,cos(err))` 的尖锐截止，改为 `0.3 + 0.7·max(0,cos(err))` 下限，
  去掉「背对目标立刻停」的硬切换，便于回归。副作用：规则基线 48 → 44（略降 8%）。

### 2.5 BC + DAgger `bc.py`
- 重构出 `_rule_labels` / `_det_action`；新增 `collect_policy_data`（on-policy 采集 + 专家重标注）
  与 `dagger()`（迭代增广数据集再训练，修复合误差）。

### 2.6 MAPPO `mappo.py`
- 新增 `warmup_critic()`：用**与 rollout 一致的随机采样**做蒙特卡洛回报，预拟合集中 Critic，
  避免随机 critic 早期产生噪声优势、把 BC 策略洗掉。

### 2.7 训练入口 `train.py` + 课程驱动 `train_curriculum.py`
- 新增参数：`--stage`、`--dagger-rounds`、`--critic-warmup`、`--std-init`、`--gamma`、
  `--entropy-coef`、`--load-actor`、`--out`。
- 新增 `train_curriculum.py`：按 c0→c1→c2→full 逐级「加载上轮 checkpoint → BC/DAgger → critic 预热 → 低 lr RL 微调」。

## 3. 关键实验结果

### 3.1 各阶段规则基线 vs BC（seed 1，20 回合 + DAgger）

| 阶段 | 规则基线交付量 | BC/DAgger 交付量 | 结论 |
| --- | --- | --- | --- |
| c0（单卸载） | 10.0 | 10.0 | 完全复现 |
| c1（单链挖装运） | 20.0 | 20.0 | 完全复现 |
| full（全资源） | 44.0 | 36.0（DAgger 4 轮） | 82% |

> 备注：full 下普通 BC 只有 0~12（且不稳定），DAgger 4~6 轮稳定到 36；DAgger 8 轮反而退化为 8
> （on-policy 采样漂移，专家重标注引入大修正）。**DAgger 4 轮是当前 sweet spot。**

### 3.2 RL 微调现状（问题）

- **从零 RL（c1/full）**：策略坍缩到「原地不动」局部最优（负的势能塑形主导 → 交付 0）。
- **BC + RL 微调（full）**：即使低 std（0.14）+ critic 预热，交付量在 8~32 间**振荡**，
  无法稳定 ≥ 36。根因：交付量指标对微小策略扰动**不连续**（一步偏差就断链归零），
  且 critic 在随机 rollout 上价值估计仍不够准（value_loss 6~32），优势噪声推动策略来回摆动。

## 4. 根因小结（本日定位）

1. **BC 学不会 go-to-goal**：`atan2(目标角)−yaw` 的角度减法含环绕歧义 → 转向符号学反。
   → 用**车体系子目标**解决。
2. **从零 RL 坍缩**：负的势能吸引奖励对随机探索平均为负 → 学会「站住不动」逃避惩罚。
   → 用 BC/DAgger 预热 + 课程 + critic 预热规避（不依赖从零探索）。
3. **RL 微调不稳定**：交付量指标不连续 + critic 价值噪声 → 微调来回摆动。
   → 待收尾：更低 lr、更低 std、调 `--gamma`、必要时对 BC 加 KL 正则。
