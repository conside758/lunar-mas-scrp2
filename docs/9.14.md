## 三、未达标原因（按重要性排序）

### 原因 1：固定场景「压不出」注意力的价值（② 未达标的根本原因）

- 固定 3 车 / 3 资源场景里，**展平观测（32 维）已经足够表达任务**：每个资源/队友槽位固定，
  普通 MLP Actor 可以直接记住槽位位置，无需「按实体集合动态聚焦」。
- 于是 `RoleAwareActor` 的注意力只带来了**更多参数（70k vs 21k）和更难优化的结构**，没有信息增益：
  BC 层面与普通 Actor 持平（都 36），RL 层面在共享优势下反而更易被洗掉（C=28.6）。
- 换句话说：**在固定场景里，角色感知是「更难的优化问题」，而不是「更强的表达」**。它只能靠
  HAPPO 反事实基线「不输在 RL 洗掉」（D=36.0±0.0），却无法「赢」。

### 原因 2：普通 Actor + MAPPO 在固定场景「恰好能赢」（拉高了对基线，使 ② 更难）

- 普通 Actor（展平）+ 共享优势 MAPPO 在固定场景能把 BC 从 36 **改进到 44**（5 种子中 3 次 44），
  这是唯一一个「RL 微调优于 BC」的单元。
- 于是无角色基线被抬到 40.8，而角色感知 HAPPO 只能回到 36，二者差 4.8（p=0.014）——**不是角色感知
  太差，而是固定场景对展平 Actor 太友好**。要达成 ②，需要换到「展平不友好、注意力友好」的场景
  （即变规模/动态重规划，见原因 5）。

### 原因 3：交付量指标不连续，RL 精修噪声大、方差高

- `delivered` 是**离散跳变**的（卸载一次加一车斗量，对「到没到卸载点/装没装满」这类阈值极敏感），
  对策略微小扰动不连续。
- 这导致：① RL 在噪声下优化「鲁棒性」而非「确定性最优」，微调常跌破 BC（历史上 full 阶段 8~32 振荡）；
  ② HAPPO 反事实优势在近确定性策略下 **a≈a_cf → A_i≈0**，几乎不更新 → 只能「冻结」36、无法「改进」；
  ③ 单种子方差大（A 在 36~44、E 在 20~36 之间跳）。

### 原因 4：三种训练动力学在「近确定性精修」下的机制差异

- **HAPPO 反事实**（D）：反事实优势在 a≈a_cf 时天然趋于 0 → **稳定但冻结**，无法把 BC 推高。
- **MAPPO 共享优势**（A/C）：能把展平普通 Actor 推到 44（A），但会把注意力结构洗掉（C=28.6）。
- **HASAC**（E/F）：熵最大化离线目标 `α·logπ − Q` **持续漂移**近确定性策略，最不稳定（E=32、F=28.8）。
- 结论：**当前没有任何一种动力学能「在固定场景既稳定又向上改进角色感知」**——这正是 ② 卡住的算法侧原因。

### 原因 5：角色感知的价值在变规模/动态重规划的「BC 层面」成立，但 RL 精修反而不稳

- §9.2 BC 层面：变规模/动态重规划场景下，注意力确实优于展平——样本效率（20 回合 BC 29.5 vs 12.3）、
  动态重规划（重生后重规划事件 1.1 vs 0.2，交付 25.3 vs 12.9）。
- **但接上「BC + HAPPO 反事实 RL 精修」后（seed 0/1/2）**：
  - 角色感知 HAPPO 反事实（G）：从 BC 均值 36.1 **跌到 16.8**（19.9 / 3.8 / 26.8）；
  - 无角色展平 MAPPO（H）：基本持平 BC（31.1 ≈ 30.2）。
- 根因：变规模场景回报方差更大 → QCritic 噪声更大 → 反事实优势持续漂移策略；注意力结构对 RL 漂移
  **更敏感**，而「展平 + 共享优势 MAPPO」反而更稳。**故里程碑 ② 在「变规模 + RL 精修」下仍未达成**
  （16.8 < 31.1）。

### 原因 6：Stage 2 的 Gazebo 迁移仍卡在 Scout「探索」行为（③ 部分未达成）

- Gazebo 侧：Stage 2 规则基线已跑通（交付 20.0），Scout 步态已提速 4.6×。
- 但 **BC/DAgger 学习策略在 Gazebo 交付 0**：Scout 的 go_to 精度/方向在 BC 下退化、离目标越走越远
  （「跑飞」），DAgger 一轮未改善。根因是 Stage 2 新增的「Scout 探索」行为比 Stage 1 更难学
  （BC 对硬阈值/尖锐非线性回归的固有平滑问题 + 替身动力学假设叠加）。

## 四、已澄清的关键结论（供后续引用）

1. **HAPPO 反事实基线是「角色感知不退化」的必要条件**：RA+MAPPO=28.6 → RA+HAPPO 反事实=36.0（p=0.0011），
   旧版只有顺序更新、无反事实仅 20.0。
2. **反事实不是无脑更好**：普通 Actor + 反事实反而略差（B=34.4 < A=40.8，p=0.011），它专门修复
   「角色异构信用分配」，不是通用提升。
3. **HASAC 在本精修场景不如 HAPPO**：SAC 熵最大化离线目标持续漂移（E/F 均低于 B/D），其优势应在
   「从零训练/强探索」场景体现。
4. **注意力为「变规模泛化 + 动态重规划」买单（BC 层面）**：固定场景无优势，变规模/动态场景有样本效率
   与重规划优势；但**接 RL 精修后注意力更易漂移**（G=16.8 < H=31.1），价值停留在模仿层面。
5. **RL 精修洗掉 BC 是全局瓶颈**：固定场景（§9.1）与变规模场景（§9.2）一致——任何 RL 精修都难稳定
   优于 DAgger-BC；注意力结构放大该漂移，展平 + 共享优势 MAPPO 相对最稳。

## 五、下一步方向（达成 ② 的候选路径）

1. **放弃「BC + RL 精修」依赖，改走「纯 BC/DAgger + 变规模」论证**：既然注意力价值在 BC 层面成立
   （样本效率 + 动态重规划），可直接以「变规模/动态场景下注意力 BC ≥ 展平 BC」作为角色感知的验收证据，
   避开 RL 精修不稳定这道坎。
2. **（若坚持 RL）修 RL 精修稳定性**：std 退火/确定性策略梯度/奖励方差进一步降低（降低 QCritic 噪声），
   或把反事实 Q 换成更低方差的优势估计，再做变规模 RL 对比。
3. **强化动态重规划评测**：把「资源耗尽重生」作为正式维度，量化重规划事件数 + 重生后新增交付。
4. **（可选）角色专属观测**：scout 去 cargo 等，进一步拉开角色结构差异。
5. **（可选）Gazebo Stage 2**：专修 Scout 的 go_to（到点停车/单独训练）。
