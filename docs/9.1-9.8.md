## 2. 本阶段做了什么

### 2.1 训练架构重构（共享 → 异构）

- 把「三车共享一个 Actor（角色 one-hot 区分）」重构为**每车一个独立 Actor + 一个集中 Critic**。
- PPO 更新从「三车 logprob 求和后的联合 ratio」改为标准的**逐 Agent ratio × 共享优势**。
- 目的：消除角色间梯度干扰与容量共享，为后续角色感知 HAPPO/HASAC 打底。

### 2.2 观测与奖励修正

- 观测每车 **31 维 → 29 维**：去掉 vx/wz（替身指令速度与 Gazebo 实际速度不一致，保留会造成
  分布外输入）；保留「车体系子目标」这一关键特征。
- 奖励：势函数塑形修正了目标切换时的虚假跳跃；新增奖励分量记录（dig/load/deliver/app/step）便于诊断。
- 新增域随机 `--domain-rand`（速度/转向 50~90% 缩放），增强策略鲁棒性。

### 2.3 定位并解决 sim-to-sim 迁移差距（本阶段最核心工作）

替身训练的策略迁移到 Gazebo 后完全失效（交付 0~4），逐步排查：

1. **实测转向动力学**（`turn_test`）：纯转向（vx=0, wz=0.8）效率 **≈50%**，但「边前进边转向」
   效率骤降到 **~8~13%** → 慢的不是转向，是「边转边走」。
2. **根因**：BC/DAgger 学 go-to-goal 时，会把规则里的「背对目标时原地转向（vx=0）」平滑成
   「vx≈0.1~0.3 慢速前进 + 转向」，恰好落入 Gazebo 最差的「边转边走」区间，于是原地画圈、无法会合。
3. **解法**：放弃「替身训练→迁移」，改为 **Gazebo 内直接收集规则示范做 BC + DAgger**，
   用真实动力学数据训练，从根上消除差距。

### 2.4 Gazebo 内 BC + DAgger 管线（新交付物）

| 文件 | 作用 |
| --- | --- |
| `collect_gazebo_data.py` | Gazebo 内跑规则基线，存 `(encoded_obs, rule_action)` 示范 |

## 4. 关键技术结论（可复用经验）

1. **车体系子目标**是让 go-to-goal 可被回归学习的关键：免去「目标角 − 车航向」的带环绕角度减法。
2. **BC 对硬阈值/尖锐非线性有固有平滑**：规则里的「原地转向」会被学成「慢速前进+转向」，
   在真实机器人上恰好最差。
3. **sim-to-sim 迁移不能只看速度缩放**：纯转向 ~50%、边转边走 ~8%，二者差异巨大，域随机
   只按速度缩放覆盖不了这种「组合运动退化」。
4. **Gazebo 内 BC + DAgger 是消除迁移差距的可靠手段**：直接用真实动力学示范，收敛快且稳定。
