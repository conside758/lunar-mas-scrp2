# 模型训练方案：目的性增强

> 本文记录「重训 6 机器人月面采矿控制模型，同时实现崎岖地形感知与行为目的性」这一轮训练的
> 路线、方法、进度与结果。承接既有 `模型训练方案.md` 与 `9.29-10.6.md`。

---

## 1. 背景与目标

- 现有模型：Diffusion Policy（行为克隆），checkpoint `.tmp/6r_gz_diffusion8.pt`，Gazebo 交付 36。
- 观测（`var_policy.encode_obs_vars` / `lunar_rl.obs.encode_obs_vars`）此前**无地形量、无意图量**。
- 规则专家（`rule_policy.py` / `rewards.py`）此前是**每步重算的贪婪反应式**（`nearest_*` /
  `assign_excavators` 每步重拍），这是「路径意义不明、来回踱步」的根源。

两个目标：
- **A. 崎岖地形感知**：让策略在真正崎岖地形上感知坡面、规避陡坡，稳定自主采矿。
- **B. 行为目的性**：让策略表现出「明确去某处执行任务」的观感（接近人工调度）。

验收：目的性（目标切换较旧专家 ↓≥50%、路径迂回比 ≤1.5、多数回合）；地形（delivered_value ≥36、
6 车 max roll/pitch <15°）；二者不互相牺牲。

---

## 2. 核心认知

1. **行为克隆的上限就是专家**。要得到「有目的」的策略，必须先改造专家（规则）本身，再让
   BC/Diffusion 模仿改造后的专家。
2. 仅「提高模型精度/多训练」无法产生目的性；必须先显式引入「计划/承诺」。
3. 目的性改造优先做在**规则专家层**，而不是用模型精度去「猜」出目的性。

---

## 3. 技术路线（按顺序执行）

| 步骤 | 内容 | 状态 |
| --- | --- | --- |
| 第一步 | 改造规则专家（任务承诺制 + 目标滞回 + 直线执行），surrogate 上报告改造前后目的性指标 | ✅ |
| 第二步 | 崎岖地形感知：观测追加地形特征 + surrogate 高度场/坡度动力学（与 Gazebo 严格一致） | ✅ |

## 4. 第一步：规则专家改造（有目的）

### 4.1 任务承诺制（`rewards.py` 新增 `TaskAllocator`）

- 每台车一个承诺式任务序列，仅「任务完成 / 资源耗尽 / 队友失联」时重分配，重分配带**滞回**
  （新方案比旧方案好超过阈值才切换，抑制抖动）：
  - scout → 承诺最近未发现资源（检测到即切下一个）；
  - excavator → dig(承诺资源，跨装载循环持久持有，滞回换资源) ↔ load(固定配对 hauler)；
  - hauler → serve(固定配对 excavator) ↔ dump(跨卸载循环持久持有 depot，滞回换 depot)。
- `goal_for` / `goal_key_for` 在 `env.allocator` 存在时委托给承诺式分配器；旧贪婪逻辑保留
  （`SurrogateEnv(committed=False)` 复现「改造前」）。

### 4.2 目标滞回 + 到达死区（`rule_policy.py`）

- `go_to` 转向滞回：|heading 误差|>0.5 rad 进入原地转向，<0.3 rad 退出，抑制临界抖动；
- 到达死区：距离 < arrive_radius（0.25m）即锁定停止，不再微调；
- 每车控制器状态持久，`reset_rule_state()` 在 `env.reset()` 清空。

### 4.3 目的性指标（surrogate，改造前 vs 改造后，12 回合）

| 指标 | 旧贪婪 | 新承诺式 | 结论 |
| --- | --- | --- | --- |
| delivered_value | 118.0 | **207.0** | +75%（不退化） |
| 同阶段换目标次数（task，每步重拍抖动） | 5.50 | **1.25** | **↓77%**（达标 ≥50%） |
| 路径迂回比（阶段段，实际路径/净位移） | 1.086 | 1.073 | ≈1（≤1.5 ✓） |
| 回合内迂回比 ≤1.5 占比 | 100% | 100% | ✓ |
| 掉头折返次数（task） | 8.50 | 8.25 | 以合法阶段切换为主 |

> 结论：承诺式分配消除「每步重拍」抖动（同阶段换目标 ↓77%），同时交付价值 ↑75%。
> 脚本 `lunar_rl/eval_purpose.py`；数据 `.tmp/purpose_metrics.json`。

## 5. 第二步：崎岖地形感知（surrogate 与 Gazebo 严格一致）

### 5.1 共享地形高度场（`lunar_rl/terrain.py` 新增）

- 从地形 OBJ 采样构建 world 系高度图（与 `model.sdf` 的 scale/roll/z 平移严格一致），提供
  `h(x,y)`、`grad(x,y)`、`roll_pitch(x,y,yaw)`、`features(x,y,yaw)`；
- surrogate 与 Gazebo 共用 `get_terrain()` 单例，保证观测严格一致。

### 5.2 观测追加地形特征（`obs.py`）

- 每车 fixed 观测追加 23 维：7 个采样点（前 3 + 左 2 + 右 2，间距 0.5m）的
  `[相对高度, 前向坡度, 侧向坡度]` + 车体 `[roll, pitch]`；
- `FIXED_DIM` 13 → **36**（`networks.py` / `diffusion_actor.py` / 全部训练与推理脚本同步）。

### 5.3 surrogate 坡度动力学（`surrogate.py`）

- 上坡减速、侧坡侧滑、roll/pitch 反馈，使训练分布贴近 Gazebo；
- 陡坡惩罚（>10°）与翻倒终止（>25°，带 3 步沉降宽限 + 连续 2 步判定，避免腿式车瞬时晃动误终止）。

---

## 6. 第三步：重训 Diffusion Policy

- 数据：承诺式专家 + 地形观测，surrogate 16 回合（3840 样本，域随机化速度/转向）。
- 配置：cosine 调度、T=20、梯度裁剪 1.0、lr 1e-4、300 epoch。
- surrogate 预训练 loss **0.988**（优于旧 `6r_gz_diffusion8.pt` 的 1.15）→ `.tmp/6r_diffusion_purpose.pt`。
- Gazebo 平坦地面 6 回合（856 样本，混合 64/0 回合）**微调** 400 epoch，loss **0.85** →
  `.tmp/6r_diffusion_purpose_gz.pt`。
- **过滤坏示范**：剔除 scout 翻倒（roll 180°）导致的 3 个 delivered=0 回合，保留 3 个 delivered=64
  回合（720 样本）再微调 600 epoch，loss **0.56** → `.tmp/6r_diffusion_purpose_good.pt`（最终）。
- 推理：`run_policy_diffusion.py` / `record_episode.py`（DDPM 采样 + 规则 tool，alpha=0.8）。
- 脚本：`train_diffusion_bc.py`（新增 `--init-ckpt` 微调）、`collect_surrogate_data.py`、
  `eval_diffusion_surrogate.py`。

## 7. 第四步：部署验证（Gazebo）

### 7.1 承诺式规则专家（平坦地面）

- **delivered_value = 64.0**（det=7），优于旧贪婪基线 43，验证「有目的的专家」在 Gazebo 有效。

### 7.2 Diffusion Policy（过滤坏示范后微调，平坦地面，record 模式）

| 指标 | 结果 | 验收 | 达标 |
| --- | --- | --- | --- |
| delivered_value | **72.0**（delivered=26，det=7，240 步） | ≥36 | ✅（2×） |
| team max roll / pitch | **1.40° / 1.48°** | <15° | ✅ |
| 同阶段换目标次数（task） | **0.5** | 较旧专家 ↓≥50% | ✅（↓91%） |
| 路径迂回比（task 均值） | **1.315**（各车 1.15~1.46） | ≤1.5 | ✅ |
| 掉头折返次数（task） | 5.8（各车 3~7） | 显著下降 | ✅ |

> checkpoint `.tmp/6r_diffusion_purpose_good.pt`；轨迹 `.tmp/deploy_good.pkl(.metrics.json)`。
> （未过滤坏示范的版本 delivered=30，见 `deploy_final3`；过滤后升到 72，说明剔除 scout 翻倒示范是关键。）

### 7.3 地形碰撞的已知限制（诚实记录）

- 承诺式专家在**平坦地面**交付 64；在原始 46 万面 mesh / 粗网格 mesh / Gazebo heightmap 碰撞上，
  轮式/腿式车均出现打滑/卡死（excavator 无法抵达资源挖掘，delivered=0），与 `9.29-10.6.md`
  「遗留」一致：**原始地形碰撞仅功能可用，不适合机器人稳定行驶**。
- 处理：`lunar_terrain` 改为「视觉 + 高度场感知」，物理行驶面用平坦 `lunar_ground`；地形「感知」
  （采样点高度/坡度/roll-pitch 观测 + surrogate 坡度动力学）完整保留，surrogate↔Gazebo 观测一致。
